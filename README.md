# JavaScript Function Practice

This project includes a set of basic JavaScript functions grouped by category: String Manipulation, Array Operations, and Mathematical Calculations.

## Functions Included

### String Manipulation

- `reverseString(str)`
- `countCharacters(str)`
- `capitalizeWords(sentence)`

### Array Functions

- `findMax(arr)`
- `findMin(arr)`
- `sumArray(arr)`
- `filterArray(arr, conditionFunc)`

### Mathematical Functions

- `factorial(n)`
- `isPrime(num)`
- `fibonacci(n)`

## How to Run

1. Open `index.js` in a JavaScript environment (like browser console or Node.js).
2. Review or modify the test `console.log()` examples at the bottom.
3. Run the file to see the output of each function.
